# 02 輸出課程資訊

- 難度：基礎

## 題目說明

程式會輸出課程名稱、使用語言與週次，但第二個 `std::cout` 敘述的文字尚未填好。修改這個敘述，讓輸出符合下列格式。

這裡的「第二個輸出敘述」不是原始碼的第二行；請依程式內容定位。

## 輸入格式

本題沒有輸入。

## 預期輸出

```text
Course: APCS
Language: C++
Week: 01
```

每個冒號後有一個半形空格，每筆資訊各占一行。

## 觀察重點

- 雙引號內的文字如何對應到終端機的輸出？
- `\n` 放在不同位置，會如何影響換行？
- 修改原始碼後，為什麼需要重新編譯？
