# 01 修正字串輸出

- 難度：基礎

## 題目說明

起始程式缺少一個雙引號，無法通過編譯。閱讀編譯器回報的檔名、行號與錯誤內容，修正程式，使它輸出指定的兩行文字。

本題練習區分「編譯失敗」與「程式可以執行，但輸出不正確」。

## 輸入格式

本題沒有輸入。

## 預期輸出

```text
Hello, C++!
This is my first program.
```

## 提示

<details>
<summary>如何閱讀錯誤訊息</summary>

先找 `main.cpp` 的行號，再檢查該行附近的字串是否以雙引號開始及結束。編譯器標示的位置是檢查起點，不一定就是需要修改的位置。

</details>

修正後儲存、重新編譯並執行，再核對大小寫、標點與換行。
