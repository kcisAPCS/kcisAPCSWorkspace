# 04 讀取並輸出整數

- 難度：基礎

## 題目說明

讀取兩個整數，依輸入順序分別輸出在兩行。練習使用 `std::cin` 讀取資料，再用 `std::cout` 加上標籤輸出；不需要進行計算。

## 輸入格式

輸入兩個整數，以空白分隔。每個整數介於 -1000 與 1000 之間。

## 輸出格式

第一行輸出 `First: ` 與第一個整數；第二行輸出 `Second: ` 與第二個整數。冒號後有一個半形空格，不要輸出輸入提示。

## 範例輸入

```text
12 34
```

## 範例輸出

```text
First: 12
Second: 34
```

## 自行測試

試試看輸入包含 0、負數，或把兩個整數分成兩行輸入，確認程式仍依序讀取並輸出。
