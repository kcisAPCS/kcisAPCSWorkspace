# 06 製作文字選單

- 難度：進階
- 類型：自由練習
- 不使用 Judge

## 練習內容

使用 `std::cout` 設計一個文字選單，例如待辦清單、記帳程式或檔案工具的主畫面。

至少包含一行標題、三個編號選項，並讓排版容易閱讀。你可以修改起始文字，或增加、刪除輸出敘述。

本週只製作顯示畫面，不需要讀取使用者輸入，也不需要實作各選項的功能。

## 可調整的部分

- 選單標題與各項功能名稱。
- 選項順序、空行與分隔線。
- 操作說明文字。

## 自我檢查

- 程式可以編譯並執行。
- 選項編號與文字清楚，沒有不必要的空行。
- 修改後重新編譯，確認畫面顯示的是最新版本。

本題沒有唯一正確輸出，可以保留自己的設計。
